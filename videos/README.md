# Demo videos (DEMO MODE)

Used by the `file` camera type (`python run.py --demo`) so the whole
detection → MQTT → WebSocket → dashboard workflow can be shown without a phone.

* `people-detection.mp4`, `person-bicycle-car-detection.mp4` — from
  [intel-iot-devkit/sample-videos](https://github.com/intel-iot-devkit/sample-videos),
  licensed CC BY 4.0 (Intel Corporation).

You can add your own clips (e.g. a fire video for testing the fire model) and point
a camera at them in `config/cameras.json`.
